Multispectral Fusion Detection for Intelligent Vision

ThermoVision is a next-generation AI vision platform that combines RGB imagery with Infrared sensing to deliver highly reliable object detection under challenging environmental conditions such as darkness, fog, smoke, and partial occlusion. Powered by YOLOv8, PyTorch, OpenCV, and FastAPI, ThermoVision performs real-time multispectral fusion, object segmentation, distance estimation, and asynchronous video processing through a scalable backend.

✨ Key Features

ThermoVision is designed to provide accurate multispectral object detection, even in environments where traditional computer vision systems struggle. By intelligently combining RGB and Infrared information, the system achieves higher robustness and improved situational awareness.

🚀 Dual Stream Fusion

Simultaneously processes RGB and Infrared inputs before intelligently merging detections to improve confidence, reduce false positives, and maintain accuracy under poor visibility.

🌡 Infrared Simulation

When dedicated thermal hardware is unavailable, ThermoVision generates high-quality simulated infrared imagery using CLAHE enhancement, allowing developers to test fusion algorithms without expensive sensors.

📏 Distance Estimation

Estimates the real-world distance of detected objects using calibrated camera parameters and class-specific object dimensions, enabling navigation and safety applications.

🎭 Mask Fusion

Combines segmentation masks from multiple imaging modalities using weighted fusion techniques to produce cleaner object boundaries and more accurate localization.

🎥 Video Analytics

Processes long-duration videos asynchronously with job scheduling, status polling, and downloadable outputs for large-scale analysis.

⚡ High Performance API

Built on FastAPI and Uvicorn to provide fast inference, scalable deployment, and seamless integration into modern AI applications.

📡 API Endpoints

Endpoint Method Description

/detect/image POST Performs multispectral image fusion detection.
/detect/image/visualize POST Returns annotated visualization with bounding boxes.
/video/process POST Queues complete video processing jobs.
